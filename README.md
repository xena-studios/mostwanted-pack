# MostWanted resource pack

The built resource pack for [MostWanted](https://mostwantedmc.com), served from here because Minecraft clients (and Minehut) download it from `raw.githubusercontent.com`.

| File | What it is |
| --- | --- |
| `mostwanted-pack.zip` | The latest pack |
| `mostwanted-pack.sha1` | Its SHA-1 and the copy under `packs/` it names, which the server reads to know when it changed |
| `packs/<sha1>.zip` | Each published pack under its own hash; the newest 10 are kept |

Everything here is published automatically from a private repository. Don't open pull requests: they'd be overwritten.
